# 启核溯源队 · CRTC 2026 机器人

四轮麦克纳姆轮全向底盘 + 三舵机机械臂 + PS2 无线手柄遥控，主控 STM32F103C8T6。

- **底盘**：4 × 直流减速电机 + 60mm 麦克纳姆轮，2 块 DRV8833 驱动（IN/IN 接法，1kHz PWM）
- **机械臂**：三自由度舵机机械臂（底座旋转 / 大臂俯仰 / 齿轮四连杆夹爪）
- **操控**：PS2 2.4G 无线手柄（右摇杆行驶/平移，左摇杆自转，十字键与肩键控制舵机）
- **电源**：2 节 18650（7.4V）动力母线 + 5V 降压模块（舵机独立供电）
